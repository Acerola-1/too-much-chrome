Too Much Chrome

あなたの Mac に、Web エンジンアプリがいくつ隠れているか。

Too Much Chrome は macOS 上の Chromium / WebView ベースのアプリ——Electron、CEF、NW.js、Tauri、Wails、そして Chrome・Edge・Brave などのフルブラウザ——をすべてスキャンし、ストレージ容量とエンジンのバージョン健康度を計測します。

名前はネタ、スキャンは本気。

最新版をダウンロード ソースを見る

スクリーンショットスキャン結果を、ひと目で

機能ハイライト一度のスキャンで、全体像を

本物のスキャン

/Applications とユーザーフォルダのすべてのアプリを、ひとつずつ精査。名前を変えた Electron アプリも、Bundle ID の指紋で正確に見抜きます。

容量の計測

アプリ本体だけでなく、~/Library に潜むキャッシュやデータも計上。集計と重複排除を経て、真の占用が一目瞭然です。

バージョン健康度

各フレームワークの公式最新版とリアルタイムで比較し、緑から赤の 5 段階で評価。オフライン時は、内蔵ベースラインに自動で切り替えます。

総覧と深掘り

総数・容量・タイプ分布・ランキングを、ひとつのパネルに。アプリを選べば容量内訳とインストール先まで掘り下げられ、Finder でそのまま開けます。

Swift ネイティブ

SwiftUI で丹念に。スキャンはバックグラウンドスレッドで完結し、終われば去るのみ。常駐プロセスは残しません。macOS 26 では Liquid Glass が自動で輝きます。

結果はあなたの Mac だけ

ログイン不要、広告なし、収集も一切なし。唯一の通信は、各フレームワークの最新版確認。スキャン結果があなたの Mac を離れることはありません。

検出方式フレームワークごとの識別確度はさまざま。各段階をありのままに表記します

Tier 1 · 高精度

Electron / CEF / NW.js

フレームワークのディレクトリ名と Bundle ID の二重指紋で判別し、誤認はほぼありません。フレームワークをリネームしても（例: QQNT.framework）、Bundle ID の com.github.Electron は隠せません。

Tier 2 · 実験的

Tauri / Wails

この二つは明確なフレームワーク指紋を残さないため、Bundle ID・リソースディレクトリ・バイナリ内のビルドパス痕跡から推測します。garble で難読化された Wails は検出できない既知の制限として、実験的と正直に表記しています。

Tier 3 · 一覧のみ

フルブラウザ

Chrome、Edge、Brave などのブラウザはそのまま一覧表示し、Chromium ベースラインでバージョンを評価。バージョン体系が特殊なものは、バイナリ内の UA 文字列で補完します。
