Too Much Chrome

あなたの Mac に、Web エンジンアプリがいくつ隠れているか。

Too Much Chrome は macOS 上の Chromium / WebView ベースのアプリ——Electron、CEF、NW.js、Tauri、Wails、そして Chrome・Edge・Brave などのフルブラウザ——をすべてスキャンし、ストレージ容量とエンジンのバージョン健康度を計測します。

最新版をダウンロード ソースを見る

機能ハイライト容量もバージョンも健康度も、一度のスキャンで

🔍

本物のスキャン

/Applications と ~/Applications 直下の .app を列挙。Electron / CEF / NW.js はフレームワークのディレクトリ名と plist の Bundle ID で判別し、ほぼ 100% の精度。Tauri / Wails は実験的なキーワード検出です。

💾

容量の計測

アプリ本体の再帰的な割り当てサイズに加え、~/Library 配下のユーザーデータ（Application Support / Caches / Containers）を Bundle ID とアプリ名で二重照合し、重複を除いて集計します。

🩺

バージョン健康度

公式ソース（Electron / Chromium / Tauri / Wails）のオンラインベースラインと照合して 5 段階で判定。オフライン時は内蔵アンカーにフォールバックし、緑から赤まで一目で分かります。

📠

スキャンライン演出

コピー機のスキャンラインが実際のスキャン進捗と連動。光の位置がそのまま進捗バーになり、アプリが見つかるたびにアイコンがぼやけから現れます。

📊

レポートパネル

総数、ストレージ内訳（本体 vs データ）、タイプ別ドーナツチャート、ストレージ上位 5 件、バージョン健康度を、右側のガラスパネルにまとめて表示します。

🖱️

詳細ポップオーバー

アプリをクリックするとストレージ内訳とインストールパスを表示、Finder で表示もワンクリック。ランキング行とグリッドのアイコンは連動ハイライトし、⌘R でいつでも再スキャンできます。

検出方式フレームワークごとに信頼度が異なる。そのまま正直に表示します

Tier 1 · 高精度

Electron / CEF / NW.js

Contents/Frameworks のディレクトリ名と plist の Bundle ID の二重シグナル。リネームビルド（例: QQNT.framework）も com.github.Electron.framework を保持するため、ディレクトリ名に加えた第二の特徴になります。

Tier 2 · 実験的

Tauri / Wails

Bundle ID とリソースディレクトリのキーワードに加え、メインバイナリ内のビルドパス痕跡をフォールバックに使用。開発者の命名規約に依存し、garble で難読化された Wails は検出できません（既知の制限）。

Tier 3 · 一覧のみ

フルブラウザ

Chrome / Edge / Brave / Arc / Vivaldi / Opera などの Chromium 系ブラウザを一覧表示し、Chromium ベースラインで判定。バージョン体系が異なるビルドはメインバイナリの "Chrome/x.y.z.w" UA 文字列から抽出します。

ダウンロードとインストールDMG は Apple の公証済み。開いたらすぐ使えます

1

DMG をダウンロード

GitHub Releases から最新の TooMuchChrome-<バージョン>.dmg を取得

2

Applications へドラッグ

DMG を開いて Too Much Chrome を Applications フォルダへドラッグ

3

起動

Launchpad または Applications から起動。最初のスキャンが自動で始まります

macOS 14 以降 Apple Silicon（M シリーズ） 公証済み · オフラインでも動作

ビルドSwiftPM プロジェクト。macOS 26 では Liquid Glass が自動で有効に

開発

# .app をビルドして起動（scripts/build-app.sh dev を実行）
./launch.sh
./launch.sh cli  # ヘッドレススキャン CLI（tmc-scan）

ビルドとテスト

swift build
swift test
swift run tmc-scan --online

Xcode で Package.swift を開いて Run することもできます。配布（署名 + 公証 + DMG）は scripts/build-app.sh を通して行います。
