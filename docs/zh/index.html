Too Much Chrome

看看你的 Mac 里藏了多少网页引擎应用

Too Much Chrome 扫描 macOS 上所有基于 Chromium / WebView 的应用——Electron、CEF、NW.js、Tauri、Wails，以及 Chrome、Edge、Brave 这类完整浏览器——并统计它们占用的存储空间与版本健康度。

名字是个梗，扫描是认真的。

下载最新版 查看源码

界面预览扫描结果，一览无遗

功能亮点一次扫描，尽显全貌

真实扫描

/Applications 与用户目录中的每个应用，逐一查验。即便 Electron 应用更名改姓，Bundle ID 指纹亦能精准识别。

体积统计

应用本体之外，~/Library 中深藏的缓存与数据同样计入。聚合、去重，真实占用一目了然。

版本健康度

与各框架官方最新版本实时比对，绿至红五档评级，健康状态一目了然。无网络时，自动退回内置基准。

总览与深究

总数、占用、类型分布与排行，尽在一块面板。点选任一应用，即可深入查看存储构成与安装位置，或直接于 Finder 中打开。

Swift 原生

SwiftUI 原生打造。扫描于后台线程完成，阅毕即退，不留常驻进程。macOS 26 上，液态玻璃自动呈现。

结果只留在你的 Mac

无需登录，没有广告，更无任何收集。唯一的联网请求，是核对各框架的最新版本；扫描结果，从不离开你的 Mac。

检测分层不同框架的识别把握各不相同，每一档都如实标注

Tier 1 · 高准确率

Electron / CEF / NW.js

以框架目录名与 Bundle ID 双指纹识别，几无误判。即便框架被更名（如 QQNT.framework），Bundle ID 中的 com.github.Electron 标识仍无所遁形。

Tier 2 · 实验性

Tauri / Wails

两者均无明显的框架指纹，依托 Bundle ID、资源目录与二进制内的构建路径特征推断。经 garble 混淆的 Wails 应用无法识别，这一已知局限如实标注为实验性。

Tier 3 · 仅列出

完整浏览器

Chrome、Edge、Brave 等浏览器直接列出，版本按 Chromium 基准评估；版本方案特殊者，由二进制内的 UA 字符串补全。
